# T7B Residual-Carrying Memory Design

## Purpose

T7A established a negative result: a sequence of individually small compatible partial writes can still accumulate into forgetting. T7B isolates one narrower hypothesis:

> **Does carrying a signed residual of collateral route drift across writes prevent the sequence-level failure that scalar per-write compatibility missed?**

This gate does not add compensation search, new candidate directions, growth, sparse coding, or a new highway. It uses the same frozen 12 target-only candidate matrices as T7A and changes only how compatibility state is remembered across accepted writes.

## Claim boundary

If T7B passes, the allowed claim is:

> In this fixed shared recurrent model and frozen 12-write stream, a signed carried memory of collateral hidden-trajectory drift supports safer continual learning than resetting compatibility after each write, and outperforms an otherwise matched scalar cumulative-debt controller.

T7B does **not** establish general continual-learning superiority, biological plausibility, automatic capacity detection, new-route growth, or that the T6 causal predictor can estimate the carried residual without direct measurement.

## Frozen world

Reuse T7A without changing:

- seed model `make_seed_model(seed=23)`;
- proposal/calibration/evaluation datasets and their seeds;
- `DEMO_SCHEDULE = (0, 1, 2, 1, 0, 2) * 2`;
- candidate generation anchored to the accept-all trajectory;
- exact 12 candidate identities generated by the existing target-only proposal search;
- scale bank `SCALE_BANK = (1.0, 0.75, 0.5, 0.25, 0.125)`;
- minimum target improvement `1e-4`;
- evaluation metrics and switch-penalty implementation.

No policy may rotate, regenerate, optimize, or compensate a candidate direction. A committed update must be exactly `alpha * candidate.delta_w` for one `alpha` from the frozen scale bank.

## Residual route signature

The compatibility memory lives in **recurrent hidden-trajectory response space**.

For skill `k`, take the first `48` calibration examples of that skill and compute

```math
H_k(W) = \operatorname{vec}\left(h_{1:T}^{(1)},\ldots,h_{1:T}^{(48)}\right),
```

using `batch_hidden_trajectories`; omit the initial all-zero state `h_0`.

For a current anchor `A_k`, define the signed collateral residual

```math
R_k(W) = H_k(W) - A_k.
```

The reported scalar magnitude is RMS hidden-state displacement

```math
\rho_k(W) = \frac{\|R_k(W)\|_2}{\sqrt{|R_k|}}.
```

For a temporary candidate step from `W` to `W'`, its signed step residual is

```math
r_k = H_k(W') - H_k(W).
```

Therefore the carried vector update is linear in response space:

```math
R_k' = R_k + r_k.
```

Because the finite trajectory response is remeasured at the current model, the sum telescopes exactly to `H_k(W') - A_k`; no linearization claim about the nonlinear RNN is required.

## Moving anchors

A skill is not treated as collateral damage while it is the target being intentionally learned.

After an accepted update targeting skill `s`:

- set `A_s <- H_s(W_new)`;
- set `R_s <- 0`;
- reset the scalar attacker debt for `s` to `0`;
- for every non-target skill `k != s`, keep its anchor fixed and carry the collateral residual forward.

This means T7B remembers **unresolved collateral route drift from the latest intentionally accepted version of each skill**, not every historical change to that skill forever.

## Budget without T7B tuning

Do not tune a new residual threshold from T7B outcomes.

Before running either cumulative controller, replay the already-frozen T6 reject-only policy on the same 12 proposals. Compute the collateral hidden-trajectory RMS residual after each accepted reject-only write using the same moving-anchor rule. Define one common residual budget

```math
B = \max_{t,k}\rho_k^{reject-only}(t).
```

If numerical roundoff makes this less than `1e-12`, the world is invalid and T7B must stop rather than invent a threshold.

Both cumulative attackers use exactly this same `B`.

Interpretation: T7B may not allow a protected route to stray farther, in RMS hidden-trajectory space, than the existing reject-only safety baseline already tolerated.

## Policies

Run these policies on the identical frozen 12 proposal matrices.

### 1. T6 reject-only

Existing binary dynamic-risk guard. Reference safety baseline.

### 2. T7A scalar safe-step

Existing per-write risk-threshold controller. Recorded negative baseline.

### 3. Scalar cumulative debt attacker

Maintain one nonnegative scalar debt `d_k` per skill.

For each candidate scale, measure `r_k` on every non-target protected skill and compute

```math
q_k = \frac{\|r_k\|_2}{\sqrt{|r_k|}}.
```

Accept the largest target-useful scale satisfying

```math
d_k + q_k \le B
```

for every protected skill. After acceptance, update `d_k <- d_k + q_k` for non-target skills and reset the target skill debt to zero after moving its anchor.

This attacker remembers cumulative magnitude but discards sign and direction. Its debt can never be repaired by cancellation.

### 4. Signed residual-carrying controller — T7B

Maintain the vector `R_k` for every skill.

For each candidate scale, measure the signed finite step residual `r_k` on every non-target skill. Accept the largest target-useful scale satisfying

```math
\frac{\|R_k + r_k\|_2}{\sqrt{|R_k|}} \le B
```

for every protected skill.

After acceptance, carry `R_k <- R_k + r_k` for non-target skills and re-anchor/reset the target skill as defined above.

### 5. Finite per-step control

Keep the existing T7A finite one-step damage control as context only. It is not a sequence-level oracle and never informs T7B.

## Repair event

A distinctive signed-memory event occurs when an accepted candidate is target-useful and reduces a protected route's existing residual magnitude:

```math
\|R_k + r_k\|_2 < \|R_k\|_2 - 10^{-8}.
```

Record the event index, target skill, protected skill, candidate seed, scale, residual norm before, residual step norm, and residual norm after.

The scalar cumulative-debt attacker cannot produce a debt decrease by construction.

## Frozen success criteria

T7B passes only if all of the following hold on `seed=0` without changing the world, budget rule, scale bank, or candidate directions after seeing the result:

1. **Identical stream:** all compared learners receive the exact same 12 candidate identities as T7A.
2. **Direction purity:** every nonzero T7B write is exactly `alpha * candidate.delta_w` for `alpha` in the frozen scale bank.
3. **Escapes freeze:** T7B makes at least `3` nonzero writes.
4. **Preserves T7A safety target:** final old A/B mean accuracy is at least `reject_only_old_skill_accuracy - 0.02`.
5. **Preserves switching target:** final switch penalty is at most `reject_only_switch_penalty + 0.005`.
6. **Recovers useful learning:** final mean accuracy is at least both `reject_only_mean_accuracy + 0.01` and `base_mean_accuracy + 0.005`.
7. **Signed memory beats scalar debt:** T7B makes at least `2` more nonzero writes than the scalar cumulative-debt attacker, while its final old A/B mean is no worse than scalar debt by more than `0.01`, and its final mean accuracy exceeds scalar debt by at least `0.005`.
8. **Actual cancellation exists:** at least `2` accepted T7B events contain a repair event on a protected skill.
9. **Budget respected:** every accepted T7B event leaves every protected residual RMS at or below `B + 1e-12`.
10. **Regression:** T0-T7A and the new T7B receipt pass on Python 3.11 and 3.12.

If these criteria fail, freeze the result as a negative. Do not relax the budget or success margins.

## Diagnostics to report regardless of outcome

Report:

- common residual budget `B`;
- candidate identities and selected scales for every policy;
- nonzero-write counts;
- final A/B/C accuracy, mean accuracy, old A/B mean, and switch penalty;
- final signed residual RMS per skill;
- final scalar debt per skill;
- number and details of repair events;
- event-by-event T7B residual norms before/after;
- whether any failure is due to protective stagnation, residual budget exhaustion, lack of cancellation opportunities, or task-performance damage despite bounded route drift.
